# STYLE ZONE – Fashion Store Website

STYLE ZONE is a fashion store website built using HTML, CSS and vanilla JavaScript.

It showcases clothing collections for Men, Women, and Kids, including new arrivals and promotional offers, with a clean, responsive layout, a working shopping cart, wishlist, search and filtering.

This project is ideal for learning front-end basics and demonstrating UI design skills.

## Features

- Clean and modern fashion store UI, responsive down to mobile screens
- Navigation menu with category sections
- Live product search and an "in stock only" filter
- Add to Cart with a slide-out cart drawer (quantity controls, remove items, subtotal, checkout)
- Wishlist (heart) button on every product card
- Product cards with images, descriptions, prices and availability status
- Promotional section with discounted prices
- Customer reviews section
- Newsletter signup form
- Footer with social links and copyright

## Technologies Used

- HTML5
- CSS3 (Flexbox, media queries)
- Vanilla JavaScript (localStorage-backed cart & wishlist)
- No frameworks or build tools required — just open `index.html`
