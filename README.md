# &nbsp;	STYLE ZONE – Fashion Store Website



STYLE ZONE is a simple and stylish fashion store website built using HTML and CSS.

It showcases clothing collections for Men, Women, and Kids, including new arrivals and promotional offers, with a clean layout and modern design.



This project is ideal for learning front-end basics and demonstrating UI design skills.





### Features



Clean and modern fashion store UI



Navigation menu with category sections



Product cards with:



* Images
* Descriptions
* Prices
* Availability status



Promotional section with discounted prices



Responsive-friendly layout (desktop-focused)



Footer with copyright



### Technologies Used



HTML5



CSS3



No frameworks or libraries used (pure frontend)
